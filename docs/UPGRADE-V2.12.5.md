# TripFlow V2.12.5 — Neutral Surfaces & Accent Colors

Nâng từ V2.12.4. Không cần chạy migration mới; database vẫn 2.12.0.

1. Giữ cấu hình môi trường Supabase hiện tại.
2. Thay source, chạy `npm ci`, `npm test`, `npm run test:theme-audit`, `npm run build`.
3. Push lên repo hosting đang dùng để deploy; bản source này chưa được push/deploy.
4. Chấp nhận cập nhật app/PWA. Chọn tím: nền sáng trắng/xám, nền tối đen/xám; nút và icon nhấn tím. Màu đã lưu được giữ nguyên.
5. Thử Mặc định, màu tự chọn, đóng/mở lại. Nếu cần quay lại, deploy source V2.12.4; không cần đổi database.
